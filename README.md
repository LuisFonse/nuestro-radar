# 📡 Nuestro Radar

Boletín diario de Luis y Jocelyn: salud y ofertas TENS, tecnología, panoramas en la Región de Valparaíso, casas en venta y un muro para dejarse mensajes.

- **Página:** https://luisfonse.github.io/nuestro-radar/
- `index.html` — la edición del día (se actualiza cada mañana).
- `config.js` — URL y anon key de Supabase para el muro.
- `supabase/setup.sql` — tabla, reglas y funciones del muro.
